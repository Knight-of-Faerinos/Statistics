Exercise 1: Welford's Recurrence Formulas

📝 Mathematical Derivation of Welford's Algorithm

To compute the sample variance efficiently in a single pass without storing all data points, we must derive a recursive formula for the Sum of Squares (SS). We start from Knuth's recurrence for the mean:

Mₙ = Mₙ₋₁ + (xₙ - Mₙ₋₁) / n

The Sum of Squares at step n is defined as the sum of squared deviations from the current mean:

SSₙ = Σ (xᵢ - Mₙ)²
SSₙ = Σ [ (xᵢ - Mₙ₋₁) + (Mₙ₋₁ - Mₙ) ]²
SSₙ = Σ (xᵢ - Mₙ₋₁)² + 2(Mₙ₋₁ - Mₙ) Σ (xᵢ - Mₙ₋₁) + n(Mₙ₋₁ - Mₙ)²

Since the sum of deviations from the previous mean Σ(xᵢ - Mₙ₋₁) for the first n-1 terms is exactly 0, the middle term cancels out for the previous points. Through algebraic substitution of the mean difference, the expression beautifully simplifies to:

SSₙ = SSₙ₋₁ + (xₙ - Mₙ₋₁)(xₙ - Mₙ)

The Sample Variance (s²) can then be extracted at any step by dividing the Sum of Squares by Bessel's correction (n - 1):

s²ₙ = SSₙ / (n - 1)

💻 Core Logic Implementation (3 lines)

This elegant mathematical property translates into highly efficient, numerically stable code that avoids catastrophic cancellation:

let delta = x - mean;
mean += delta / n;
SS += delta * (x - mean); // Note: 'mean' is already updated to Mₙ
