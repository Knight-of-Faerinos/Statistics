2A. Row-Conditional Frequencies: P(F = fⱼ | X = xᵢ)

Distribution of F given each category of X. Under independence, every row matches the marginal distribution P(F).

2B. Column-Conditional Frequencies: P(X = xᵢ | F = fⱼ)

Distribution of X given each category of F. Demonstrates the symmetry of independence: P(X | F) = P(X) across all columns.

3. Expected Frequencies Under Independence (Eᵢⱼ)

Theoretical cell counts computed as Eᵢⱼ = (Row Totalᵢ × Col Totalⱼ) / N assuming P(X, F) = P(X)P(F).

4. Pearson Standardized Residuals: Rᵢⱼ = (Oᵢⱼ − Eᵢⱼ) / √Eᵢⱼ

Measures cell-by-cell departure from independence. Values with |Rᵢⱼ| > 2.0 indicate statistically significant excess (green) or deficit (red) at α ≈ 0.05.

📝 Theoretical Framework: Statistical Independence

  • Probabilistic Definition: Two random variables X and F are statistically independent if and only if their joint probability factorizes into the product of their marginals: P(X = xᵢ, F = fⱼ) = P(X = xᵢ) · P(F = fⱼ) for every pair (xᵢ, fⱼ).
  • Symmetric Conditional Invariance: Independence holds if and only if P(F = fⱼ | X = xᵢ) = P(F = fⱼ) for all xᵢ, which is mathematically equivalent to P(X = xᵢ | F = fⱼ) = P(X = xᵢ) for all fⱼ.
  • Chi-Square, Cochran's Condition & Cramér's V: Pearson's χ² aggregates squared standardized residuals (χ² = Σ Rᵢⱼ²) and follows a χ² distribution with df = (r − 1)(c − 1) provided Cochran's rule holds (at least 80% of expected cells Eᵢⱼ ≥ 5 and none < 1). Because χ² scales linearly with sample size N, Cramér's V normalizes it to [0, 1] to quantify true association strength independently of N.

📝 Conclusions: Statistical Association vs. Causality

  • Interpreting Significance vs. Effect Size: Using the synthetic generator above, keeping a small association strength (e.g., 20%) while increasing N from 50 to 3,000 causes the p-value to drop below 0.0001 while Cramér's V stays near 0.15. Statistical significance proves an association is unlikely due to chance, whereas effect size measures its practical magnitude.
  • Association is Symmetric; Causality is Directional: Swapping X and F yields the exact same χ², p-value, and Cramér's V. Contingency tables detect co-variation, never causal direction.
  • Confounding & Spurious Correlations: Strong statistical dependence between X and F can be induced by an unobserved third variable (a confounder Z, such as organization size or network exposure) driving both variables simultaneously. Proving causality requires randomized experiments or structural causal inference rather than observational counts alone.
