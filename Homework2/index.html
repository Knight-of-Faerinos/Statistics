From Wallet Seed to Ethereum Address

Hashing, Key Derivation and Cryptographic Primitives

Generating an Ethereum address relies on a modular pipeline rather than a single algorithm. Each cryptographic standard serves a specific role to ensure mathematical security, cross-wallet compatibility, and human error prevention.

The Cryptographic Pipeline

Mnemonic Phrase BIP-39

Generates initial entropy (128-256 bits) and converts it into a 12 or 24-word readable phrase for easy user backup.

Master Seed & Derivation BIP-32 / BIP-44

Converts words into a 512-bit seed via PBKDF2. Deterministically derives the key tree using the standard m/44'/60'/0'/0/0 Ethereum path.

Private / Public Key secp256k1

Multiplies the private key on the elliptic curve to generate the Public Key. A mathematically one-way trapdoor function ensuring fund ownership.

Raw Ethereum Address Keccak-256

Hashes the public key to compress its size. The last 20 bytes of the resulting hash form the base hexadecimal address.

Checksummed Address EIP-55

A second hash determines the capitalization of the address characters, introducing a backward-compatible visual checksum to prevent typing errors.
