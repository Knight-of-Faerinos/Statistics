    How it Works & Statistical Exploration

    1. The Math: In elliptic curve cryptography, we don't multiply numbers normally. To find $kG$ (Public Key), we start at the Base Point $G$ and mathematically "add" it to itself $k$ times using finite field geometry modulo 17.

    2. The Avalanche Effect: Try changing the Private Key slightly (e.g., from 6 to 7). Notice how the final Public Key jumps to a completely unpredictable new location. This lack of input-output correlation is why recovering the private key from the public key (ECDLP) is computationally difficult.

    3. Hashes vs ECC: While hashes (like SHA-256) destroy all mathematical structure to create a random fingerprint, ECC maintains a strict algebraic group structure. This structure is what allows us to create digital signatures (like in Ethereum) while still acting as a cryptographic one-way function.
